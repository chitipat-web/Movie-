# 🎬 MovieHub — รวมเว็บดูหนัง & สตรีมมิ่งยอดนิยม

เว็บรวมลิงก์บริการสตรีมมิ่ง **ถูกลิขสิทธิ์** ยอดนิยม — หนัง ซีรีส์ อนิเมะ กีฬา เพลง และเว็บข้อมูลหนัง ให้ค้นหาได้ง่ายในที่เดียว

## ✨ ฟีเจอร์

- 🔍 **ค้นหา** ตามชื่อเว็บ คำอธิบาย หรือแท็ก (รองรับภาษาไทย)
- 🗂️ **หมวดหมู่** — สตรีมมิ่ง / ดูฟรีถูกลิขสิทธิ์ / อนิเมะ / กีฬา / เพลง / ข้อมูลหนัง
- ⭐ **รายการโปรด** — บันทึกเว็บที่ใช้บ่อย (เก็บใน localStorage ของเบราว์เซอร์)
- 🏷️ ป้ายบอกว่าเว็บไหน **ดูฟรี / มีแบบฟรี / ต้องสมัครสมาชิก**
- 📱 รองรับมือถือ (Responsive)
- ⚡ เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้องติดตั้งอะไร ไม่ต้องมี backend

## 🚀 วิธีใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์ง่าย ๆ:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

### Deploy ขึ้น GitHub Pages

1. ไปที่ **Settings → Pages** ของ repo
2. เลือก Source เป็น branch ที่ต้องการ (root `/`)
3. เว็บจะออนไลน์ที่ `https://<username>.github.io/<repo>/`

## ➕ วิธีเพิ่มเว็บใหม่

แก้ array `SITES` ใน `index.html` โดยเพิ่ม object รูปแบบนี้:

```js
{
  name: "ชื่อเว็บ",
  url: "https://example.com",
  cat: "streaming",          // streaming | free | anime | sport | music | info
  color: "#e50914",          // สีโลโก้ตัวอักษร
  price: "freemium",         // free | freemium | paid
  desc: "คำอธิบายสั้น ๆ",
  tags: ["หนัง", "ซีรีส์"],
}
```

## ⚠️ ข้อจำกัดความรับผิดชอบ

เว็บนี้เป็นเพียง **ตัวรวมลิงก์** ไปยังผู้ให้บริการสตรีมมิ่งอย่างเป็นทางการเท่านั้น ไม่ได้เป็นเจ้าของ จัดเก็บ หรือให้บริการเนื้อหาใด ๆ ทั้งสิ้น และรวมเฉพาะบริการที่ถูกลิขสิทธิ์
